# 钱小迹小程序隐私保护指引

生效日期：2026年9月18日
版本：1.0

本隐私保护指引适用于钱小迹小程序（以下简称“本小程序”）。本小程序由 **[开发者主体名称]** 运营（以下简称“我们”）。

使用本小程序前，请仔细阅读并理解本指引。你使用或继续使用本小程序，即表示你已阅读并同意我们按照本指引处理相关信息。对于需要单独取得授权的功能，我们会在使用前向你说明用途，并按照微信平台的授权流程取得同意。

## 一、我们处理的信息

### 1. 微信登录和账户信息

当你使用本小程序时，我们会通过微信登录流程获取用于识别账户的微信用户标识（包括 openId 等必要标识），用于创建和维护你的账本、区分不同用户的数据，并保障账户数据不被混淆。

如果你主动完善个人资料，我们可能处理：

- 昵称；
- 头像；
- 性别；
- 你主动填写的邮箱或联系方式。

### 2. 普通账单信息

当你新增、编辑或导入账单时，我们会处理你主动提供的：

- 收入或支出类型；
- 金额；
- 日期和时间；
- 分类；
- 标题、备注等描述信息。

这些信息用于账单展示、日历、月度/年度汇总、统计分析、预算计算和成就进度。

### 3. 账单导入

当你使用“账单导入”功能时，你可以选择 CSV、Excel 等账单文件。我们会处理文件中与账单导入有关的内容，例如日期、类型、分类、金额和备注，用于：

- 解析和校验文件；
- 在导入前展示预览结果；
- 在你确认后写入你的账本。

文件解析过程中可能经过我们的服务器处理。导入文件本身不会作为永久附件保存在账本中；确认导入后，账单字段会作为账本记录保存。包含无法识别分类或格式错误的记录不会被自动写入。

### 4. 账单导出和邮箱发送

当你使用“账单导出”功能时，我们会处理：

- 你填写的接收邮箱；
- 你选择的开始日期、结束日期和账单类型；
- 导出范围内的账单数据。

我们会生成带密码的 ZIP 文件，并通过邮件服务发送到你填写的邮箱。导出记录会保存邮箱、导出范围、导出类型、文件名、发送状态和时间等信息。ZIP 解压密码以加密形式保存，密码有效期为 7 天，过期后不能通过导出记录获取。

邮件发送可能由邮件服务提供商处理。请确认你填写的是本人有权使用的邮箱，不要填写他人的邮箱或未经授权的邮箱。

### 5. 固定收支

当你创建“固定收支”规则时，我们会处理：

- 收支类型；
- 分类；
- 金额；
- 每月执行日；
- 开始日期；
- 备注；
- 规则启用、停用状态。

规则启用后，我们会在达到执行日时自动生成对应的账本流水。每个月同一规则最多生成一条流水；停用或删除规则后，不再生成新的流水，已经生成的历史流水不会因此自动删除。

### 6. 借出管理

当你使用“借出管理”功能时，我们会处理：

- 借款人名称；
- 借出金额；
- 已收回金额；
- 借出日期；
- 预计归还日期；
- 备注；
- 待收回、部分收回、已收回等状态。

这些信息用于展示借出总额、已收回金额、待收回金额和单笔借出记录。借款人名称及备注可能包含他人的个人信息，请在获得必要授权并确认使用目的后填写。

### 7. 意见反馈和图片

当你提交意见反馈时，我们会处理你主动填写的反馈内容、联系方式以及你主动选择上传的图片。图片可能上传至文件存储服务，用于展示和处理反馈。请不要在反馈中上传身份证、银行卡、密码、验证码等与问题处理无关的敏感信息。

## 二、我们使用信息的目的

我们仅在以下目的范围内使用相关信息：

1. 提供登录、账单记录、导入、导出、固定收支和借出管理功能；
2. 展示账单列表、日历、统计、预算和成就；
3. 发送你主动请求的账单导出邮件；
4. 处理意见反馈、故障排查和服务通知；
5. 防止重复导入、重复生成固定收支流水和其他影响账本准确性的行为；
6. 遵守适用法律法规、监管要求和微信平台规则。

我们不会将账单内容用于与你无关的广告画像或向其他用户公开。未经你的授权，我们不会出售你的个人信息。

## 三、信息共享和委托处理

为提供必要功能，我们可能将最少必要的信息委托给以下类型的服务商：

- 微信登录服务：用于完成小程序登录和用户标识获取；
- 邮件服务商：用于发送你主动请求的 ZIP 导出文件；
- 文件存储服务商：用于保存头像、反馈图片等你主动上传的文件。

委托处理仅限于实现对应功能所需范围。我们会通过合同、配置、访问控制等方式要求服务商保护信息安全。除法律法规另有规定或取得你的单独授权外，我们不会共享与功能无关的信息。

## 四、信息保存和删除

1. 账单、固定收支规则和借出记录会在你使用期间保存，以便提供历史查询和统计功能。
2. 导出记录会保留必要的操作信息；导出密码超过有效期后不能再获取。
3. 你可以通过小程序现有的编辑、删除功能管理部分账单和个人资料。
4. 如需查询、更正、删除个人信息，或申请注销账户，请联系 **[隐私联系邮箱]**。我们会在核验你的身份后处理请求。
5. 删除或注销请求可能受到法律法规规定的保存期限、争议处理、审计和安全要求限制；限制原因会向你说明。

## 五、信息安全

我们会采取访问控制、权限隔离、传输加密、密码加密保存、参数校验和操作日志等措施保护信息安全。导出 ZIP 使用密码保护，解压密码不会直接写入导出文件记录的明文存储字段。

但是，任何网络传输和存储都不能保证绝对安全。请妥善保管微信账户、邮箱和导出密码，不要将 ZIP 文件或解压密码发送给无关人员。

## 六、你的权利

在符合法律法规和平台规则的前提下，你可以：

- 查询和查看账单、固定收支及借出记录；
- 修改或删除可编辑的账单、固定收支和借出记录；
- 停用固定收支自动执行；
- 获取导出文件及有效期内的解压密码；
- 请求访问、更正、删除你的个人信息；
- 撤回不影响此前基于同意进行处理的授权；
- 申请注销账户。

你可以通过 **[隐私联系邮箱]** 联系我们行使上述权利。为了保护账户安全，我们可能要求你完成身份核验。

## 七、未成年人保护

本小程序主要面向具备相应民事行为能力的用户。未成年人使用本小程序应在监护人同意和指导下进行。若监护人发现未成年人未经同意向我们提供了个人信息，请通过 **[隐私联系邮箱]** 联系我们，我们会在核实后依法处理。
